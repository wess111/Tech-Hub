# Hardware visual assets

Created with the built-in image generation tool on 2026-10-17 for Tech-Hub. These are original illustrative renders; they do not depict the precise manufacturer models named in the component catalog. No manufacturer photography is bundled.

- `empty-case.png`: overhead view of an open, empty ATX case, used as the interactive workbench backdrop.
- `parts-atlas.png`: transparent 3x3 hardware atlas, used for inventory previews and installed components. Rows: motherboard / CPU / thermal compound; cooler / RAM / NVMe SSD; GPU / PSU / case fan.

Prompts:

1. Photorealistic product-render texture for an educational PC assembly simulator: a square, straight-down orthographic view of a matte black ATX case with its side panel removed. Empty motherboard tray, black PSU shroud along the bottom, chassis screws, rear IO cutout, cable grommets and expansion brackets. Neutral studio lighting, no installed board/CPU/GPU/RAM, no logos or text.
2. Transparent square 3x3 sprite atlas with nine equal cells and isolated, realistic black/silver hardware. Consistent overhead camera. Row 1: ATX motherboard with empty socket and slots, silver desktop CPU, thermal paste syringe. Row 2: tower air cooler, RAM DIMM, M.2 SSD. Row 3: dual-fan GPU, modular PSU, case fan. No labels, logos, grid lines or watermark.

Images remain in their generated format with alpha preserved. CSS controls atlas framing; appearance is illustrative and specifications determine simulation behavior.
